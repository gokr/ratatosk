# flutter_it Agent Skills

Skills for AI coding assistants following the [Agent Skills](https://agentskills.io) standard.
They are bundled with the `flutter_it` package and installed with `dart run skills@ get`
(or from this repository with `dart run skills@ add flutter-it/flutter_it`).

| Skill | Covers |
|---|---|
| `flutter-it-overview` | What the construction set is, which package to use when |
| `flutter-it-architecture` | Pragmatic Flutter Architecture: services, managers, views, proxies |
| `flutter-it-feed-datasource` | Paginated feeds / infinite scroll with FeedDataSource |
| `flutter-it-get-it` | get_it registration, scopes, async init |
| `flutter-it-watch-it` | watch_it reactive widgets, handlers, cached factory params |
| `flutter-it-command-it` | command_it commands, restrictions, error handling |
| `flutter-it-listen-it` | listen_it operators, chain lifecycle, reactive collections |

The individual packages ship the same content as `get-it-expert`, `watch-it-expert`,
`command-it-expert` and `listen-it-expert`.

See [SKILLS.md](SKILLS.md) for installation details, naming rules and how the skills are maintained.
